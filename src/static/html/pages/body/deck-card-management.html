A song with no release year is kept but never dealt, so you can add it now and fill the year in later.

Import Songs

Upload a .json file containing an array of songs. Each entry may use exactly these keys: 

{
  "title": "Heroes",
  "artist": "David Bowie",
  "year": 1977,
  "videoId": "https://youtu.be/...",
  "category": "Rock"
}

videoId accepts a YouTube link or a bare video ID. Blank or invalid links still import the song (with no video id) and mark it unavailable for Dead Videos. year and category are optional. Songs already in this deck with the same video id, or the same title + artist + year, are skipped. An unrecognized genre imports the song without one. Max 1000 songs, 2 MB per upload.
